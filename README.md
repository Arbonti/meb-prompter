# 📊 MEB Prompter – MEB Deneme Sınav Analiz Sistemi

**T.C. Millî Eğitim Bakanlığı (MEB) – Aydın** bünyesinde gerçekleştirilen **uzun dönem staj** kapsamında geliştirilen kurumsal otomasyon aracı.

## 📌 Proje Hakkında

MEB Prompter, okul bazlı deneme sınavı sonuçlarını otomatik olarak analiz eden, karşılaştırmalı raporlar oluşturan ve heatmap görselleştirmeleri sunan bir web tabanlı otomasyon sistemidir.

## 🚀 Özellikler

- 🏫 **Okul bazlı sınav analizi** – Çok sayıda okulu karşılaştırmalı analiz
- 📈 **Heatmap görselleştirmesi** – Soru/konu bazlı başarı haritaları
- 🤖 **AI modülü** – Yapay zeka destekli yorum ve öneri sistemi
- 📊 **Otomatik raporlama** – Sınav verilerinden PDF/sunum oluşturma
- 🔍 **Öğrenci sorgulama** – Bireysel öğrenci performans takibi
- 💾 **CSV/JSON veri desteği** – MEB formatında veri işleme

## 🛠 Kullanılan Teknolojiler

- **HTML5 / CSS3** – Arayüz
- **JavaScript (ES6+)** – İş mantığı ve modüller
- **Python** – Veri işleme ve sunum oluşturma
- **CSV/JSON** – MEB veri formatları

## 📁 Modül Yapısı

